Imaging foundation

ImagingBaseModel

Extends SpatialBaseModel for pre-trained image backbones. Owns model loading, image data setup, and inference. Training is explicitly disabled — models are always loaded via from_pretrained().

from_pretrained(hub_id | local_path) setup_anndata(img_path_col) from_spatialdata() → AnnData get_latent_representation() _ImagePathDataset HuggingFace Hub | local .pt
Imaging class · v1

SPARL

Spatial Proteomics Analysis with Representation Learning. Loads a DINO/iBOT-pretrained Vision Transformer backbone trained on multi-channel microscopy images (IMC, JUMP-CP) and produces per-cell CLS-token embeddings. Inference-only in this release.

nn.Module wrapper SPARLModule → DinoVisionTransformer
inherits ImagingBaseModel channel_names in uns obsm["X_sparl"] sparl pkg · optional dep

Transcriptomics data flow

Inputs

AnnData / SpatialData / MuData

Counts, labels, spatial coordinates, paired spatial and single-cell tables.

Entry points

Register fields

setup_anndata(), setup_spatialdata(), and setup_mudata().

Custom fields

Spatial registry

SpatialCoordsField, NeighborhoodGraphField, index_neighbor, distance_neighbor.

Models

Train and infer

backend="cpu" | "rapids"; pretrained sources from CondSCVI or RNAStereoscope.

Outputs

Embeddings and predictions

obsm["X_scVIVA"], obsm["X_resolvi"], proportions, mapper matrices, and imputed expression.

Imaging data flow (scviva.imaging)

Inputs

Cell image crops

Per-cell file paths in adata.obs["img_path"] (PNG/TIFF) or SpatialData image table.

Entry points

Register image fields

setup_anndata(img_path_col) or from_spatialdata(sdata) → registers uns["scviva_imaging"].

Data loading

_ImagePathDataset

Loads images from disk at inference time. No augmentation. Output: (C, H, W) float tensor in [0, 1].

Inference

SPARLModule forward

Broadcasts channel_names to batch, calls DinoVisionTransformer, extracts x_norm_clstoken.

Outputs

Per-cell embeddings

obsm["X_sparl"] shape (n_cells, embed_dim). RAPIDS backend returns cupy array.
