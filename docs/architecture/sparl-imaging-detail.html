Component classes

Imaging foundation
ImagingBaseModel
scviva/imaging/base/_imaging_base.py

Abstract base for all image-based spatial models. Owns loading, data registration, and inference. Training is disabled — always loaded via from_pretrained(). Subclasses implement _build_module() and setup_anndata().

Class attributes

  • attr _default_obsm_key = "X_imaging"

Class methods (entry points)

  • cls from_pretrained(model_name_or_path: str) → Self Resolves HF repo ID or local path; loads checkpoint; calls _build_module(); sets .module.eval()
  • cls setup_anndata(adata, img_path_col, spatial_key) → None Abstract in base — subclasses register AnnDataManager fields + write uns["scviva_imaging"]
  • cls from_spatialdata(sdata, table_key, region, **kwargs) → AnnData Overrides SpatialBaseModel — subsets adata first, then calls setup_anndata. Returns AnnData (not model).
  • cls _resolve_path(model_name_or_path) → str os.path.exists → local; not isabs + "/" in name → hf_hub_download; else FileNotFoundError
  • abstract _build_module(checkpoint_data: dict) → nn.Module Subclasses reconstruct backbone from checkpoint dict and return wrapped nn.Module

Instance methods

  • method get_latent_representation(adata, batch_size, obsm_key, device, backend) → ndarray Builds DataLoader → batched forward → writes obsm[obsm_key]; backend="rapids" returns cupy
  • private _build_inference_dataloader(adata, batch_size) → DataLoader Reads img paths from adata.uns["scviva_imaging"]["img_path_col"]; wraps _ImagePathDataset
  • method train(*args, **kwargs) → NotImplementedError Always raises — pre-trained models are not trained via scviva-tools interface
Imaging model
SPARL
scviva/imaging/sparl/_model.py

Spatial Proteomics Analysis with Representation Learning. Wraps a DINO/iBOT-pretrained DinoVisionTransformer for per-cell embedding extraction from multi-channel microscopy images (IMC, JUMP-CP). v1 is inference-only.

Class attributes

  • attr _default_obsm_key = "X_sparl"

Overrides

  • cls _build_module(checkpoint_data) → SPARLModule Pops "arch" from config; instantiates DinoVisionTransformer(**config); loads teacher backbone; wraps in SPARLModule
  • cls setup_anndata(adata, img_path_col, channel_names, spatial_key) → None Registers SpatialCoordsField + writes uns["scviva_imaging"] and uns["sparl_channels"] (optional)

Typical usage

model = SPARL.from_pretrained(
  "YosefLab/sparl-imc-vitb16"
)
SPARL.setup_anndata(
  adata,
  img_path_col="crop_path",
  channel_names=["CD3","CD8","DAPI"]
)
emb = model.get_latent_representation(adata)
# adata.obsm["X_sparl"]: (n_cells, embed_dim)
nn.Module wrapper
SPARLModule
scviva/imaging/sparl/_module.py

Thin nn.Module wrapping SPARL's DinoVisionTransformer. Isolates the sparl package import to a single file. Handles the channels tensor required by the backbone internally — callers only pass image batches.

Constructor

  • init __init__(backbone: DinoVisionTransformer) Stores backbone as self.backbone (registered nn.Module sub-module)

Forward pass

  • method forward(x: Tensor) → Tensor
Input: x: (B, C, H, W) float32, values in [0, 1]
Step 1: channel_names.unsqueeze(0).expand(B, -1) → channels (B, C)
Step 2: backbone(x, channels)["x_norm_clstoken"]
Output: CLS-token embeddings (B, embed_dim)

Key design choice

backbone.channel_names is a stored tensor from training time. SPARLModule broadcasts it to batch size automatically, so ImagingBaseModel's inference loop stays model-agnostic (one module(batch) call regardless of backbone type).

Data pipeline classes

Dataset
_ImagePathDataset
scviva/imaging/base/_imaging_base.py · module-level

Minimal torch.utils.data.Dataset that resolves per-cell image paths to normalized float tensors. No augmentation — pure inference loading.

  • attr paths: list[str]
  • method __len__() → int
  • method __getitem__(idx) → Tensor(C, H, W) Calls _load_image_as_tensor(paths[idx])
Helper function
_load_image_as_tensor
scviva/imaging/base/_imaging_base.py · module-level

Loads any supported image format to a normalized float32 tensor. Handles format detection, channel ordering, and value range normalization.

Signature

  • fn _load_image_as_tensor(path: str) → Tensor(C,H,W)

Processing pipeline

1. Format detection — suffix-based:
  • .tif / .tiff → tifffile.imread()
  • other → PIL.Image.open()

2. Shape normalization
  • (H, W) → (1, H, W)
  • (H, W, C) → (C, H, W)

3. Value normalization
  • max > 1 and ≤ 255: divide by 255
  • max > 255: divide by max
  • Output: float32 tensor ∈ [0, 1]

External package — sparl (optional dependency)

sparl pkg · external
DinoVisionTransformer
sparl.models.backbones.vision_transformer · installed separately

DINO/iBOT Vision Transformer trained on multi-channel microscopy images. Accepts (B, C, H, W) images alongside a (B, C) channel-ID tensor, applies patch embedding and self-attention blocks, and returns a dict of output tokens. Only the x_norm_clstoken key is used by scviva-tools.

Key constructor params

  • paramchannel_names: list[int|str]
  • paramimg_size: int
  • parampatch_size: int
  • paramembed_dim: int
  • paramdepth: int
  • paramnum_heads: int
  • parampos_embed_type: "rope"|"learnable"

forward() output dict

  • keyx_norm_clstoken (B, D) ← used
  • keyx_norm_postokens (B, Ph, Pw, D)
  • keyx_prenorm (B, 1+N, D)
  • keymasks, attentions

Architecture variants

  • archvit (standard)
  • archflat_vit (flattened)
  • archalt_vit (channel+pos attn)
Imported only inside SPARL._build_module() — not a hard scviva-tools dep. Guards: pytest.importorskip("sparl") in all SPARL tests.

Model loading — checkpoint format & resolution

Expected checkpoint structure (.pt)

{
  "epoch": int,
  "step": int,
  "model": {
    "teacher": {
      "backbone": state_dict, ← loaded by _build_module
    }
  },
  "model_config": {
    "arch": str, ← popped, not passed to ViT
    "channel_names": list,
    "img_size": int,
    "patch_size": int,
    "embed_dim": int,
    "depth": int,
    "pos_embed_type": str,
    ... (other ViT kwargs)
  }
}

Serialized with torch.save(...). Loaded with weights_only=False — required because checkpoint contains non-tensor objects (config dicts).

from_pretrained() resolution logic

Local path

os.path.exists(path) → use as-is.
Example: "/checkpoints/sparl_imc.pt"

HuggingFace Hub

not isabs + "/" in name → detected as HF repo ID.
Calls hf_hub_download(repo_id, filename="model.pt").
Example: "YosefLab/sparl-imc-vitb16"
Note: Hub model not yet published — TODO in test suite.

After path resolved

torch.load(path) → cls._build_module(ckpt) → obj.module.eval() → return obj

End-to-end inference data flow

Cell image crops

Per-cell image files on disk or crops from a SpatialData image table. Supported formats: PNG, JPEG, TIFF.

adata.obs["img_path"] SpatialData

AnnData registration

SPARL.setup_anndata() or SPARL.from_spatialdata() writes uns["scviva_imaging"] and registers SpatialCoordsField.

uns["scviva_imaging"]

_ImagePathDataset

Reads paths from obs[img_path_col]. _load_image_as_tensor converts to float32 in [0, 1]. Batched by DataLoader (no shuffle, no augmentation).

(B, C, H, W) · [0,1]

SPARLModule.forward()

Expands backbone.channel_names → (B, C). Calls DinoVisionTransformer(x, channels)["x_norm_clstoken"].

(B, embed_dim)

Embeddings written

All batch results concatenated and assigned to adata.obsm["X_sparl"]. Optional backend="rapids" returns cupy array.

obsm["X_sparl"] (n_cells, embed_dim)

Two data entry paths

Path A — disk-based (AnnData)

# 1. Load model
model = SPARL.from_pretrained("YosefLab/sparl-imc-vitb16")

# 2. Register — img_path column holds per-cell file paths
SPARL.setup_anndata(
  adata,
  img_path_col="crop_path",
  channel_names=["CD3", "CD8", "DAPI"],
)

# 3. Infer
model.get_latent_representation(adata)
# → adata.obsm["X_sparl"]

Path B — SpatialData

# 1. Load model
model = SPARL.from_pretrained("/local/sparl_imc.pt")

# 2. Register via SpatialData
# from_spatialdata returns the AnnData
adata = SPARL.from_spatialdata(
  sdata,
  table_key="cells",
  region="imc_image",
  img_path_col="crop_path",
)

# 3. Infer
model.get_latent_representation(adata)
# → adata.obsm["X_sparl"]
